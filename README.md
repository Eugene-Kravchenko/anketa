# Анкета генеалогического исследования

Одностраничный сайт: пошаговый опросник, конструктор родового древа,
автоматическая предварительная оценка и отправка заявки в Telegram.
Никакого бэкенда — обычная статика, живёт на GitHub Pages.

## Публикация — 5 шагов

1. Создай на GitHub новый **публичный** репозиторий, например `anketa`.
2. Залей туда содержимое этой папки: `index.html`, `config.js`, `.nojekyll`, `README.md`.
   Через веб-интерфейс: **Add file → Upload files** → перетащить всё → Commit.
3. Заведи бота: в Telegram напиши **@BotFather** → `/newbot` → придумай имя →
   получишь токен вида `1234567890:AAH...`.
4. Узнай свой `chat_id`: напиши что-нибудь своему боту, затем открой в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id":123456789`.
   Это число и есть `chatId`. (Либо просто напиши боту **@userinfobot**.)
5. Впиши токен и chatId в `config.js`, закоммить. Затем **Settings → Pages →
   Source: Deploy from a branch → main / (root) → Save**.

Через пару минут сайт будет по адресу `https://<логин>.github.io/anketa/`.

## Проверка

Открой сайт, заполни имя и телефон на шаге 1, перейди на шаг 7,
поставь галочку согласия и нажми «Отправить заявку».
В Telegram должны прийти два сообщения: короткая сводка и файл со всей анкетой.

## Что где менять

| Что | Где |
|---|---|
| Токен и chat_id | `config.js` |
| Вилки цен в предварительной оценке | `index.html`, константа `PRICE` в начале `<script>` |
| Логика зелёной/жёлтой/красной зоны | `index.html`, функция `assess()` |
| Тексты вердиктов | `index.html`, объект `T` внутри `assess()` |
| Вопросы и варианты ответов | `index.html`, разметка секций `<section class="panel">` |

## Важно про токен

Токен бота лежит в `config.js` и виден любому, кто откроет исходники страницы —
иначе статический сайт не сможет ничего отправить. Практический риск —
что кто-то начнёт слать через бота мусор тебе в чат. Лечится сменой токена
у @BotFather (`/revoke`) и заменой строки в `config.js`.

Если поток заявок вырастет и мусор начнёт мешать — следующий шаг
переезд отправки на прокси (Cloudflare Worker), тогда токен уедет на сервер.

## Свой домен

**Settings → Pages → Custom domain**, вписать домен и добавить у регистратора
CNAME на `<логин>.github.io`. GitHub сам выпустит сертификат.
